Matrices</h1><p class="lead">Model fixed-size indexed data, distinguish an array object from its reference, and traverse one- and two-dimensional structures safely.</p><div class="lesson-meta"><span>Level 6 of 24</span><span>Beginner</span><span>110–150 minutes</span><span>8 concept checks</span></div></div><aside class="outcome-card"><span>BY THE END, YOU CAN</span><h2>Use arrays without index or aliasing mistakes</h2><ul><li>Create and traverse arrays.</li><li>Explain aliases and copies.</li><li>Compute aggregates in one pass.</li><li>Use jagged matrices.</li><li>Apply Arrays utilities.</li></ul></aside></section><nav class="jump-bar"><a href="#concepts">Concepts</a><a href="#examples">Examples</a><a href="#trace">Trace</a><a href="#revision">Revision</a><a href="#interview">Interview</a><a href="#practice">Practice</a><a href="#quiz">Check</a></nav><section class="lesson-section" id="concepts"><header class="section-heading"><span>CONCEPTS · MECHANISMS · TRADE-OFFS</span><h2>Arrays &amp; Matrices: Mental Models and Practice</h2><p>Learn the mechanism first, then use the API with clear assumptions, boundaries and tests.</p></header><article class="concept-block"><h3>1. Index contract</h3><p>An array is a fixed-length object of same-type elements. Valid indices are zero through <code>length - 1</code>; invalid access is checked at runtime.</p><p>Elements receive defaults, but the array reference may be null. An empty array is valid and differs from null.</p><ul><li><code>length</code> is a field.</li><li>Prefer half-open ranges.</li><li>Define empty-input behaviour.</li></ul></article><article class="concept-block"><h3>2. Traversal and aggregation</h3><p>Use an indexed loop when position matters or elements change. Enhanced for clearly expresses read-only value traversal.</p><p>Initialize minimum from the first element after handling empty input; an invented zero sentinel fails for all-negative arrays.</p></article><article class="concept-block"><h3>3. Aliasing and copying</h3><p>Array assignment copies a reference, so both names identify the same object. Mutations are shared.</p><p><code>clone</code>, <code>Arrays.copyOf</code> and <code>System.arraycopy</code> make shallow copies. Object elements remain shared references.</p><div class="concept-table-wrap"><table class="concept-table"><thead><tr><th>Operation</th><th>New array?</th><th>Result</th></tr></thead><tbody><tr><td>b=a</td><td>No</td><td>Alias</td></tr><tr><td>a.clone()</td><td>Yes</td><td>Shallow copy</td></tr><tr><td>Arrays.copyOf</td><td>Yes</td><td>Chosen length</td></tr><tr><td>arraycopy</td><td>Destination supplied</td><td>Selected range</td></tr></tbody></table></div></article><article class="concept-block"><h3>4. Matrices</h3><p>A Java 2D array is an array of row references, so rows may differ in length.</p><p>Traverse with <code>matrix.length</code> and <code>matrix[r].length</code>; validate rectangular dimensions before matrix arithmetic.</p></article></section><section class="lesson-section" id="examples"><header class="section-heading"><span>RUNNABLE JAVA</span><h2>Examples Worth Tracing</h2><p>Predict the result before running each program. Then change one value and explain the new behaviour.</p></header><article class="example-card"><header><div><span>EXAMPLE 01</span><h3>One-pass statistics</h3></div><button class="copy-code" type="button" data-copy-example="0">Copy code</button></header><div class="code-wrap"><pre><code>import java.util.Arrays;
public class Program {
    public static void main(String[] args) {
        int[] marks={72,91,65,88};
        int sum=0,max=marks[0];
        for(int mark:marks){sum+=mark;if(mark&gt;max)max=mark;}
        System.out.println(Arrays.toString(marks));
        System.out.println(max+&quot; &quot;+sum/(double)marks.length);
    }
}</code></pre></div><footer>Sum and maximum are computed in one pass; the cast preserves the fractional average.<pre>Output:
[72, 91, 65, 88]
91 79.0</pre></footer></article><article class="example-card"><header><div><span>EXAMPLE 02</span><h3>Jagged row totals</h3></div><button class="copy-code" type="button" data-copy-example="1">Copy code</button></header><div class="code-wrap"><pre><code>public class Program {
    public static void main(String[] args) {
        int[][] rows={{2,4},{7},{1,3,5}};
        for(int r=0;r&lt;rows.length;r++){
            int total=0;
            for(int value:rows[r]) total+=value;
            System.out.println(&quot;row &quot;+r+&quot; = &quot;+total);
        }
    }
}</code></pre></div><footer>Each row supplies its own length, so jagged structure is handled safely.<pre>Output:
row 0 = 6
row 1 = 7
row 2 = 9</pre></footer></article></section><section class="lesson-section" id="trace"><header class="section-heading"><span>INTERACTIVE LEARNING · PROGRAM TRACE</span><h2>Trace array after speaking your own version aloud.</p></header><div class="interview-list"><details><summary>1. Array versus ArrayList?</summary><p>Arrays have fixed length and hold primitives directly; ArrayList resizes and offers collection operations for reference types.</p></details><details><summary>2. What is array covariance?</summary><p>A subtype array may be assigned to a supertype-array reference; unsafe stores then fail at runtime.</p></details><details><summary>3. Why does b=a not copy elements?</summary><p>Array variables hold references, and assignment copies that reference.</p></details><details><summary>4. What is a jagged array?</summary><p>A 2D array whose independently allocated rows have different lengths.</p></details><details><summary>5. How can a range be copied?</summary><p>Use Arrays.copyOfRange or System.arraycopy with carefully chosen half-open bounds.</p></details></div></section><section class="lesson-section" id="practice"><header class="section-heading"><span>PROGRAMMING PROBLEMS</span><h2>Apply the Concept Independently</h2><p>Use the CodeBhavya online compiler.
