What Is Responsive Design?</h2></div></div><ul class="content-points"><li>The layout can change according to available width.</li><li>Columns can become rows on smaller screens.</li><li>Navigation can change presentation.</li><li>Images and text can scale within reasonable limits.</li><li>Controls should remain usable with touch and keyboard input.</li><li>Responsive design is about the interface, not about targeting specific phone models.</li></ul><div class="explanation-list"><p>Responsive design means creating interfaces that adapt to the available screen and interaction space. The Viewport</h2></div></div><ul class="content-points"><li>Desktop screens usually provide more horizontal space.</li><li>Mobile screens provide much less horizontal space.</li><li>The same content may need different arrangements.</li><li>Browser DevTools can simulate different viewport dimensions.</li></ul><div class="explanation-list"><p>The viewport is the visible area in which a webpage is displayed. Responsive CSS commonly reacts to the viewport width.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy="/* The layout can respond to viewport width */

Mobile-First CSS</h2></div></div><ul class="content-points"><li>Start with the simplest usable layout.</li><li>Add larger-screen improvements through media queries.</li><li>Avoid assuming that desktop is the default.</li><li>Mobile-first CSS often produces cleaner responsive rules.</li></ul><div class="explanation-list"><p>Mobile-first development starts with a layout that works well in a narrow viewport and then enhances it for larger screens.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy=".course-grid {

Fluid Widths</h2></div></div><ul class="content-points"><li>Percentages can create fluid widths.</li><li>width: 100% allows an element to fill its containing block.</li><li>max-width prevents content from becoming excessively wide.</li><li>margin-inline: auto can center a constrained container.</li></ul><div class="explanation-list"><p>A fluid layout allows elements to use available space instead of forcing a fixed width everywhere.</p></div><div class="real-example"><strong>🌍 REAL-WORLD EXAMPLE</strong><p>The content can shrink on a mobile screen while remaining comfortably constrained on a large desktop screen.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy=".content {

Flexbox — The One-Dimensional Layout System</h2></div></div><ul class="content-points"><li>display: flex activates Flexbox.</li><li>flex-direction chooses row or column.</li><li>justify-content controls the main axis.</li><li>align-items controls the cross axis.</li><li>gap creates space between flex items.</li><li>flex-wrap allows items to move onto additional lines.</li></ul><div class="explanation-list"><p>Flexbox is designed for arranging items along one primary axis. Main Axis and Cross Axis</h2></div></div><ul class="content-points"><li>With flex-direction: row, the main axis is horizontal.</li><li>With flex-direction: column, the main axis is vertical.</li><li>justify-content operates on the main axis.</li><li>align-items operates on the cross axis.</li></ul><div class="explanation-list"><p>Flexbox alignment depends on the direction of the flex container.</p></div><div class="real-example"><strong>🌍 REAL-WORLD EXAMPLE</strong><p>For a row-based menu, justify-content distributes items horizontally while align-items controls vertical alignment.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy=".menu {
