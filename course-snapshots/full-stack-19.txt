01</p><h2>What Is Node.js?</h2></div></div><p class="concept-intro">Node.js allows JavaScript to run outside the browser. Instead of using JavaScript only to control a webpage, developers can use it to build servers, APIs, command-line tools and backend applications.</p><ul class="content-points"><li><strong>Node.js is a JavaScript runtime environment.</strong></li><li>It allows JavaScript code to execute on a computer or server without requiring a browser.</li><li>Node.js uses the V8 JavaScript engine to execute JavaScript.</li><li>Node.js provides APIs for tasks such as files, networking, processes and streams.</li><li>Node.js is widely used for backend APIs and web servers.</li></ul><div class="key-idea"><span>💡</span><div><strong>Key Idea</strong><p>Node.js does not make JavaScript a different language.
