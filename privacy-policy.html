Privacy Policy

Effective date: 30 September 2026. This policy describes information used by CodeBhavya at codebhavya.com.

Information you provide

Account features use an email address and authentication information through Supabase. Depending on the feature used, the site can store learning progress, quiz answers and results, coding submissions and related activity. Support emails include the details you choose to send.

Code execution and tracing

Compiler and tracer features send source code and supplied input to the configured execution service. Current services include Render-hosted APIs. Treat code and input as information sent outside your browser; avoid submitting passwords, secret keys or confidential personal information.

Browser storage and offline use

The site uses local storage, session storage and browser caches for features such as saved lessons, preferences, progress, authentication sessions and offline access. Clearing browser data can remove local progress and saved content. Signing out does not necessarily erase all learning data or offline caches.

Service providers and technical information

Cloudflare delivers the website and downloadable resources; Supabase supports authentication and database features; execution providers process compiler and tracer requests. Providers may process IP addresses, browser or device information, request details and technical logs for delivery, security and operation. External links and embedded services have their own privacy practices.

How information is used

Information supports sign-in, saved learning activity, assessments, code execution, troubleshooting, security and replies to support requests. Account and learning data are not intended to be public unless a feature explicitly indicates sharing. Do not assume code execution is confidential storage.

Advertising

Google AdSense advertising is not enabled in this release. If advertising is introduced, this policy and applicable consent controls will be updated before ads are served.

Retention and your choices

Browser data remains until cleared or removed by the feature. Account records and submissions may remain while used for learning features. Contact us to request access, correction or deletion. Request handling depends on identity verification, applicable obligations and provider backup retention; immediate removal from every backup cannot be promised.

Students and children

The learning material can be viewed without creating an account. Younger learners should involve a parent or guardian before providing personal information or using account features. Contact us if you believe a child has supplied personal information inappropriately.

Security and changes

No online service is completely secure. Do not share account credentials or put secrets in code examples. This page will be updated when practices change.

Contact

For privacy questions or requests, email support@codebhavya.com.

Optional support payments

Razorpay processes payments made through the Support page and handles the payment details you provide in its checkout. CodeBhavya uses order and payment references, amount, currency and payment status to create and verify a contribution and investigate support requests. This checkout does not store your card number, CVV or payment passwords in CodeBhavya website code.

The Support page keeps its order reference in session storage in your browser tab to recover status after a refresh. It is not a subscription or a record of purchased learning access. Contact support with questions about your contribution or data.
