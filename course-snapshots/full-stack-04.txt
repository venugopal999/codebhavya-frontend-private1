CSS Syntax</h2></div></div><ul class="content-points"><li>Selector chooses the element.</li><li>Property identifies what you want to change.</li><li>Value specifies how it should be changed.</li><li>Declarations are normally separated by semicolons.</li><li>The declaration block is surrounded by curly braces.</li></ul><div class="explanation-list"><p>A CSS rule contains a selector followed by one or more declarations. Element, Class and ID Selectors</h2></div></div><ul class="content-points"><li>Element selector: targets all matching elements.</li><li>Class selector: begins with a dot.</li><li>ID selector: begins with #.</li><li>Classes are generally preferred for reusable styling.</li><li>IDs are more specific and should not normally be used as the main styling mechanism.</li></ul><div class="explanation-list"><p>Selectors determine which HTML elements receive a CSS rule. class="interview-list"><details class="interview-item"><summary><span>01</span>Explain the CSS cascade.</summary><div class="interview-answer"><p>The cascade resolves competing declarations by considering origin, importance, specificity and source order. The winning declaration becomes the computed style for that property.</p></div></details><details class="interview-item"><summary><span>02</span>What is CSS specificity?</summary><div class="interview-answer"><p>Specificity is the priority of a selector in the cascade. IDs are more specific than classes, while classes are more specific than element selectors.</p></div></details><details class="interview-item"><summary><span>03</span>Why should excessive specificity be avoided?</summary><div class="interview-answer"><p>Highly specific selectors are difficult to override and maintain. Simple, predictable selectors make large stylesheets easier to manage.</p></div></details><details class="interview-item"><summary><span>04</span>Explain the difference between padding and margin.</summary><div class="interview-answer"><p>Padding creates internal space between content and border. Margin creates external space outside the border.</p></div></details><details class="interview-item"><summary><span>05</span>Explain content-box versus border-box.</summary><div class="interview-answer"><p>With content-box, declared width normally applies to the content area. With border-box, the declared width includes content, padding and border.</p></div></details><details class="interview-item"><summary><span>06</span>What is CSS inheritance?</summary><div class="interview-answer"><p>Inheritance allows selected properties, such as color and font-family, to flow from parent elements to descendants unless overridden.</p></div></details><details class="interview-item"><summary><span>07</span>What is the difference between em and rem?</summary><div class="interview-answer"><p>em is relative to the relevant element&#39;s font size, while rem is relative to the root element&#39;s font size.</p></div></details><details class="interview-item"><summary><span>08</span>When would you use an attribute selector?</summary><div class="interview-answer"><p>Attribute selectors are useful when styling elements according to meaningful HTML attributes, such as input types or required controls.</p></div></details><details class="interview-item"><summary><span>09</span>Why is !important usually discouraged?</summary><div class="interview-answer"><p>It bypasses normal cascade reasoning and can create specificity conflicts that become difficult to maintain.</p></div></details><details class="interview-item"><summary><span>10</span>How do you find why a CSS rule is not working?</summary><div class="interview-answer"><p>Inspect the element in DevTools, check whether the rule matched, look for crossed-out declarations, inspect specificity and source order, and examine computed styles.</p></div></details><details class="interview-item"><summary><span>11</span>What is the box model?</summary><div class="interview-answer"><p>It describes an element as content surrounded by padding, border and margin.</p></div></details><details class="interview-item"><summary><span>12</span>Why is CSS knowledge important for React developers?</summary><div class="interview-answer"><p>React organizes UI structure and behaviour, but CSS still determines the visual presentation, spacing, responsive behaviour and usability of the interface.</p></div></details></div></section><section class="lesson-section practice-section"><p class="section-label">PRACTICE ARENA</p><h2>Now apply what you learned</h2><p
