class="lesson-section interview-section"><p class="section-label">PLACEMENT & INTERVIEW</p><h2>Explain the concept, don't just memorize it</h2><div class="interview-list"><details class="interview-item"><summary><span>01</span>What is JavaScript?</summary><div class="interview-answer"><p>JavaScript is a high-level programming language standardized through ECMAScript. It is widely used for browser applications, servers and other environments.</p></div></details><details class="interview-item"><summary><span>02</span>What is ECMAScript?</summary><div class="interview-answer"><p>ECMAScript is the standardized specification that defines the JavaScript language.</p></div></details><details class="interview-item"><summary><span>03</span>What is a JavaScript engine?</summary><div class="interview-answer"><p>A JavaScript engine is software that parses, compiles and executes JavaScript code.</p></div></details><details class="interview-item"><summary><span>04</span>What is a runtime environment?</summary><div class="interview-answer"><p>A runtime environment surrounds the JavaScript engine with additional APIs and capabilities provided by the host environment.</p></div></details><details class="interview-item"><summary><span>05</span>Name the seven primitive data types in JavaScript.</summary><div class="interview-answer"><p>string, number, bigint, boolean, undefined, symbol and null.</p></div></details><details class="interview-item"><summary><span>06</span>Are arrays primitive values?</summary><div class="interview-answer"><p>No. Arrays are objects and therefore non-primitive values.</p></div></details><details class="interview-item"><summary><span>07</span>What is typeof null?</summary><div class="interview-answer"><p>typeof null returns object. This is a historical JavaScript quirk retained for compatibility.</p></div></details><details class="interview-item"><summary><span>08</span>What is the difference between let and const?</summary><div class="interview-answer"><p>Both are block scoped. let allows reassignment, while const does not allow reassignment of its binding.</p></div></details><details class="interview-item"><summary><span>09</span>Does const make an object immutable?</summary><div class="interview-answer"><p>No. const prevents reassignment of the variable binding. Properties of the referenced object can still be changed.</p></div></details><details class="interview-item"><summary><span>10</span>Why is var generally avoided in modern JavaScript?</summary><div class="interview-answer"><p>var is function scoped and has older declaration semantics. let and const provide clearer block-scoped behaviour.</p></div></details><details class="interview-item"><summary><span>11</span>What is NaN?</summary><div class="interview-answer"><p>NaN means Not-a-Number. It represents an invalid or unrepresentable numeric result and has the JavaScript type number.</p></div></details><details class="interview-item"><summary><span>12</span>Why does NaN !== NaN return true?</summary><div class="interview-answer"><p>NaN is defined as not being equal to any value, including itself.</p></div></details><details class="interview-item"><summary><span>13</span>How should you check for NaN?</summary><div class="interview-answer"><p>Use Number.isNaN(value) when you want to determine whether a value is actually NaN.</p></div></details><details class="interview-item"><summary><span>14</span>What is the difference between null and undefined?</summary><div class="interview-answer"><p>undefined commonly indicates that a value is missing or unassigned, while null is generally used to represent intentional absence.</p></div></details><details class="interview-item"><summary><span>15</span>What is type coercion?</summary><div class="interview-answer"><p>Type coercion is the conversion of a value from one type to another. It can be explicit or implicit.</p></div></details><details class="interview-item"><summary><span>16</span>What is the difference between == and ===?</summary><div class="interview-answer"><p>== performs equality comparison with coercion, while === performs strict equality without that coercion.</p></div></details><details class="interview-item"><summary><span>17</span>Why does &#39;10&#39; + 5 produce &#39;105&#39;?</summary><div class="interview-answer"><p>The + operator can perform string concatenation. Because one operand is a string, the number participates in string concatenation.</p></div></details><details class="interview-item"><summary><span>18</span>Why does &#39;10&#39; - 5 produce 5?</summary><div class="interview-answer"><p>The - operator performs numeric subtraction, so the string &#39;10&#39; is converted to the number 10.</p></div></details><details class="interview-item"><summary><span>19</span>Are [] and {} falsy?</summary><div class="interview-answer"><p>No. Empty arrays and empty objects are truthy.</p></div></details><details class="interview-item"><summary><span>20</span>What is a good first step when debugging JavaScript?</summary><div class="interview-answer"><p>Reproduce the problem and inspect the relevant values and types before changing the code.</p></div></details></div></section><section class="lesson-section practice-section"><p class="section-label">PRACTICE ARENA</p><h2>Now apply what you learned</h2><p class="section-description">Try these problems without immediately looking at the solution.
