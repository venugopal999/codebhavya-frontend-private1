to functional components.</p></div></article><article><b>02</b><div><strong>useState</strong><p>Hook used to store state that affects rendering.</p></div></article><article><b>03</b><div><strong>useEffect</strong><p>Hook used to synchronize a component with an external system.</p></div></article><article><b>04</b><div><strong>useRef</strong><p>Hook used to hold a persistent mutable value or DOM reference without triggering rendering.</p></div></article><article><b>05</b><div><strong>Controlled input</strong><p>An input whose value is controlled by React state.</p></div></article><article><b>06</b><div><strong>Dependency array</strong><p>The list of reactive values that an Effect uses to determine when synchronization should be repeated.</p></div></article><article><b>07</b><div><strong>Effect setup</strong><p>The synchronization logic executed by an Effect.</p></div></article><article><b>08</b><div><strong>Effect cleanup</strong><p>The function returned from an Effect to stop or undo its external synchronization.</p></div></article><article><b>09</b><div><strong>Race condition</strong><p>A timing problem where asynchronous results complete in an unexpected order.</p></div></article><article><b>10</b><div><strong>Derived data</strong><p>A value calculated from existing state or props rather than stored separately.</p></div></article><article><b>11</b><div><strong>Functional updater</strong><p>A state setter form that receives the previous state and returns the next state.</p></div></article><article><b>12</b><div><strong>Form validation</strong><p>Checking submitted data against expected rules before processing it.</p></div></article></div></section><section class="lesson-section interview-section"><p class="section-label">PLACEMENT & INTERVIEW</p><h2>Explain the concept, don't just memorize it</h2><div class="interview-list"><details class="interview-item"><summary><span>01</span>What are React Hooks?</summary><div class="interview-answer"><p>Hooks are React functions that let functional components use features such as state, effects and refs.</p></div></details><details class="interview-item"><summary><span>02</span>What are the Rules of Hooks?</summary><div class="interview-answer"><p>Hooks should be called at the top level of React components or custom Hooks, not inside loops, conditions or nested ordinary functions.</p></div></details><details class="interview-item"><summary><span>03</span>What is useState?</summary><div class="interview-answer"><p>useState is a Hook that adds state to a functional component.</p></div></details><details class="interview-item"><summary><span>04</span>What is useEffect?</summary><div class="interview-answer"><p>useEffect lets a component synchronize with an external system.</p></div></details><details class="interview-item"><summary><span>05</span>When should you use useEffect?</summary><div class="interview-answer"><p>When a component needs synchronization with something outside React, such as a subscription, timer, browser API or external connection.</p></div></details><details class="interview-item"><summary><span>06</span>When should you not use useEffect?</summary><div class="interview-answer"><p>Do not use it merely for ordinary calculations, derived data or logic that belongs directly in an event handler.</p></div></details><details class="interview-item"><summary><span>07</span>What is a controlled component?</summary><div class="interview-answer"><p>A form control whose current value is driven by React state.</p></div></details><details class="interview-item"><summary><span>08</span>How do you handle a controlled text input?</summary><div class="interview-answer"><p>Store its value in state, pass that state as value and update it in onChange.</p></div></details><details class="interview-item"><summary><span>09</span>How do you handle a checkbox?</summary><div class="interview-answer"><p>Usually store a boolean and use event.target.checked in the change handler.</p></div></details><details class="interview-item"><summary><span>10</span>Why use event.preventDefault() in form submission?</summary><div class="interview-answer"><p>It prevents the browser&#39;s default navigation/submission behaviour when the application is handling the submission itself.</p></div></details><details class="interview-item"><summary><span>11</span>What is a dependency array?</summary><div class="interview-answer"><p>It lists the reactive values used by an Effect that determine when the Effect needs to synchronize again.</p></div></details><details class="interview-item"><summary><span>12</span>What happens when an Effect dependency changes?</summary><div class="interview-answer"><p>React runs the previous cleanup, then runs the Effect setup with the new values.</p></div></details><details class="interview-item"><summary><span>13</span>What is Effect cleanup?</summary><div class="interview-answer"><p>The function returned from an Effect that stops or reverses the external synchronization started by the Effect.</p></div></details><details class="interview-item"><summary><span>14</span>Why should event listeners be removed?</summary><div class="interview-answer"><p>To prevent stale subscriptions, duplicated handlers and unnecessary work after the component no longer needs the listener.</p></div></details><details class="interview-item"><summary><span>15</span>Why should intervals be cleared?</summary><div class="interview-answer"><p>Otherwise the timer can continue running after the component no longer needs it.</p></div></details><details class="interview-item"><summary><span>16</span>Can useEffect be async directly?</summary><div class="interview-answer"><p>The Effect callback itself should not be made an async function that returns a Promise as cleanup. Define an inner async function and call it, while returning a cleanup function when needed.</p></div></details><details class="interview-item"><summary><span>17</span>What is a race condition in data fetching?</summary><div class="interview-answer"><p>It occurs when multiple requests overlap and an older response finishes later and incorrectly overwrites newer data.</p></div></details><details class="interview-item"><summary><span>18</span>How can obsolete fetch results be ignored?</summary><div class="interview-answer"><p>Use cleanup logic such as an ignore flag, or use request cancellation such as AbortController when appropriate.</p></div></details><details class="interview-item"><summary><span>19</span>What is useRef?</summary><div class="interview-answer"><p>A Hook that stores a persistent mutable value without causing a re-render when the value changes.</p></div></details><details class="interview-item"><summary><span>20</span>Does changing ref.current trigger rendering?</summary><div class="interview-answer"><p>No.</p></div></details><details class="interview-item"><summary><span>21</span>When is useRef useful?</summary><div class="interview-answer"><p>For DOM references, timer IDs and other values that must persist without affecting rendered output.</p></div></details><details class="interview-item"><summary><span>22</span>What is the difference between state and ref?</summary><div class="interview-answer"><p>State updates cause rendering; changing a ref does not.</p></div></details><details class="interview-item"><summary><span>23</span>Why can an Effect cause an infinite loop?</summary><div class="interview-answer"><p>If the Effect updates state and that update changes one of the Effect&#39;s dependencies, the Effect can repeatedly trigger itself.</p></div></details><details class="interview-item"><summary><span>24</span>Why is cleanup important?</summary><div class="interview-answer"><p>It prevents resources and subscriptions created by an Effect from continuing after they are no longer needed.</p></div></details><details class="interview-item"><summary><span>25</span>Why does React development Strict Mode sometimes run setup and cleanup more than once?</summary><div class="interview-answer"><p>The extra development-only cycle helps reveal Effects whose cleanup does not correctly mirror their setup.</p></div></details><details class="interview-item"><summary><span>26</span>What is a controlled form?</summary><div class="interview-answer"><p>A form where important input values are stored in React state and the inputs receive those values from state.</p></div></details><details class="interview-item"><summary><span>27</span>Should client-side validation replace server-side validation?</summary><div class="interview-answer"><p>No. Client-side validation improves user experience, but the server must validate its own incoming data.</p></div></details><details class="interview-item"><summary><span>28</span>Why should derived data usually not be stored separately?</summary><div class="interview-answer"><p>Duplicating derived data can create synchronization problems and unnecessary state.</p></div></details></div></section><section class="lesson-section practice-section"><p class="section-label">PRACTICE ARENA</p><h2>Now apply what you learned</h2><p class="section-description">Try these problems without immediately looking at the solution.
