class="interview-list"><details class="interview-item"><summary><span>01</span>What problem does React Router solve?</summary><div class="interview-answer"><p>It maps application URLs to React UI and logic.</p></div></details><details class="interview-item"><summary><span>03</span>Why are URL parameters useful in React applications?</summary><div class="interview-answer"><p>They allow the URL to security?</summary><div class="interview-answer"><p>A browser can be manipulated by the user. Real authorization must also be enforced by the backend.</p></div></details><details class="interview-item"><summary><span>08</span>What problem does Context solve?</summary><div class="interview-answer"><p>Context reduces the need to pass widely shared values through many intermediate components.</p></div></details><details class="interview-item"><summary><span>09</span>When should Context not be used?</summary><div class="interview-answer"><p>It should not automatically replace normal props.
