class="concept-heading"><div class="concept-number">01</div><div><p class="section-label">CONCEPT 01</p><h2>1. Why Version Control Matters</h2></div></div><ul class="content-points"><li>Track changes over time.</li><li>Understand who changed what and when.</li><li>Return to an earlier working version.</li><li>Experiment without destroying the main code.</li><li>Collaborate with other developers.</li><li>Create a reliable project history.</li></ul><div class="explanation-list"><p>Software changes continuously. Developers need a reliable way to record changes, understand history, recover earlier versions and collaborate without accidentally overwriting each other&#39;s work. Version control systems solve these problems.</p></div><div class="warning-box"><span>⚠️</span><div><strong>Important</strong><p>Git is not a backup system alone. It is a version-control system that records meaningful changes to a project.</p></div></div></section><section class="lesson-section concept-section"><div class="concept-heading"><div class="concept-number">02</div><div><p class="section-label">CONCEPT 02</p><h2>2. What Is Git?</h2></div></div><ul class="content-points"><li>Git runs locally on your computer.</li><li>A repository contains project history.</li><li>Commits record snapshots of tracked changes.</li><li>Branches allow parallel lines of development.</li><li>Remote repositories allow collaboration and sharing.</li></ul><div class="explanation-list"><p>Git is a distributed version-control system. A Git repository contains project files together with metadata describing the project&#39;s history.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy="git --version

git init">Copy</button></header><pre><code>git --version

git init</code></pre></div><div class="warning-box"><span>⚠️</span><div><strong>Important</strong><p>Git and GitHub are not the same thing. Git is the version-control technology. Working Tree, Staging Area and Repository</h2></div></div><ul class="content-points"><li>Working tree contains the files you are currently editing.</li><li>Staging area contains changes selected for the next commit.</li><li>Repository contains committed history.</li><li>git add moves selected changes toward the next commit.</li><li>git commit records the staged snapshot.</li></ul><div class="explanation-list"><p>Git can be understood through three important areas: the working tree, the staging area and the repository history.</p></div><div class="code-box premium-code-box"><header><span>WORKED EXAMPLE</span><button type="button" data-copy="Working Tree
