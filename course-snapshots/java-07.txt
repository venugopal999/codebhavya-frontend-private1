OBJECT-ORIENTED DESIGN · LEVEL 07</p><h1>Strings &amp; Text Processing</h1><p class="lead">Work with immutable text, Unicode-aware APIs, efficient builders and explicit comparison rules.</p><div class="lesson-meta"><span>Level 7 of 24</span><span>Intermediate</span><span>110–150 minutes</span><span>8 concept checks</span></div></div><aside class="outcome-card"><span>BY THE END, YOU CAN</span><h2>Process text correctly and efficiently</h2><ul><li>Explain String immutability and pooling.</li><li>Compare content safely.</li><li>Use core text APIs.</li><li>Build text efficiently.</li><li>Recognize Unicode boundaries.</li></ul></aside></section><nav class="jump-bar"><a href="#concepts">Concepts</a><a href="#examples">Examples</a><a href="#revision">Revision</a><a href="#interview">Interview</a><a href="#practice">Practice</a><a href="#quiz">Check</a></nav><section class="lesson-section" id="concepts"><header class="section-heading"><span>CONCEPTS · MECHANISMS · TRADE-OFFS</span><h2>Strings &amp; Text Processing: Mental Models and Practice</h2><p>Learn the mechanism first, then use the API with clear assumptions, boundaries and tests.</p></header><article class="concept-block"><h3>1. Immutable values and the pool</h3><p>A String object cannot change after creation. Methods return a new String, which makes sharing and hashing safe.</p><p>String literals are interned, but code must compare content with <code>equals</code>, never depend on reference identity.</p><ul><li><code>==</code> compares references.</li><li><code>equals</code> compares character sequences.</li><li>Handle null before calling an instance method.</li></ul></article><article class="concept-block"><h3>2. Search, slice and normalize</h3><p><code>length</code>, <code>charAt</code>, <code>substring</code>, <code>indexOf</code>, <code>contains</code>, <code>startsWith</code>, <code>replace</code> and <code>split</code> cover common transformations. Document whether surrounding whitespace and case are significant.</p><p>Case conversion can depend on locale; use <code>Locale.ROOT</code> for machine identifiers.</p><div class="concept-note"><strong>Important:</strong> <code>split</code> accepts a regular expression, so metacharacters such as a dot need escaping.</div></article><article class="concept-block"><h3>3. Builders and Unicode</h3><p>Repeated concatenation in a loop creates intermediate objects; StringBuilder offers a mutable buffer for single-threaded construction.</p><p>String indexes address UTF-16 code units. A visible Unicode code point may occupy two chars, so use code-point APIs when full Unicode correctness matters.</p><div class="concept-table-wrap"><table class="concept-table"><thead><tr><th>Need</th><th>Tool</th><th>Reason</th></tr></thead><tbody><tr><td>Stable text value</td><td>String</td><td>Immutable and shareable</td></tr><tr><td>Repeated construction</td><td>StringBuilder</td><td>Mutable buffer</td></tr><tr><td>Thread-safe legacy buffer</td><td>StringBuffer</td><td>Synchronized</td></tr><tr><td>Unicode symbol traversal</td><td>codePoints()</td><td>Works in code points</td></tr></tbody></table></div></article></section><section class="lesson-section" id="examples"><header class="section-heading"><span>RUNNABLE JAVA</span><h2>Examples Worth Tracing</h2><p>Predict the result before running each program. Then change one value and explain the new behaviour.</p></header><article class="example-card"><header><div><span>EXAMPLE 01</span><h3>Normalize and count words</h3></div><button class="copy-code" type="button" data-copy-example="0">Copy code</button></header><div class="code-wrap"><pre><code>import java.util.Locale;
public class Program {
    public static void main(String[] args) {
        String raw=&quot;  Java   Makes Intent Clear  &quot;;
        String clean=raw.trim().replaceAll(&quot;\s+&quot;,&quot; &quot;).toLowerCase(Locale.ROOT);
        System.out.println(clean);
        System.out.println(clean.isEmpty()?0:clean.split(&quot; &quot;).length);
    }
}</code></pre></div><footer>Whitespace is normalized before counting, and locale-independent case conversion suits program data.<pre>Output:
java makes intent clear
4</pre></footer></article><article class="example-card"><header><div><span>EXAMPLE 02</span><h3>Build a CSV row</h3></div><button class="copy-code" type="button" data-copy-example="1">Copy code</button></header><div class="code-wrap"><pre><code>public class Program {
    public static void main(String[] args) {
        String[] cells={&quot;101&quot;,&quot;Ananya&quot;,&quot;CSE&quot;};
        StringBuilder row=new StringBuilder();
        for(int i=0;i&lt;cells.length;i++){
            if(i&gt;0) row.append(&#39;,&#39;);
            row.append(cells[i]);
        }
        System.out.println(row);
    }
}</code></pre></div><footer>The separator is added between cells, not after every cell, and one mutable buffer avoids repeated temporary Strings.<pre>Output:
101,Ananya,CSE</pre></footer></article></section><section class="lesson-section" id="revision"><header class="section-heading"><span>QUICK REVISION</span><h2>Recall the Essential Ideas</h2></header><div class="revision-grid"><div><b>01</b> String is immutable.</div><div><b>02</b> equals compares content; == compares identity.</div><div><b>03</b> StringBuilder suits repeated construction.</div><div><b>04</b> split uses regex.</div><div><b>05</b> Locale.ROOT suits machine normalization.</div><div><b>06</b> char indexes are UTF-16 units.</div></div></section><section class="lesson-section" id="interview"><header class="section-heading"><span>INTERVIEW QUESTIONS</span><h2>Explain, Do Not Memorize</h2><p>Open each answer only after speaking your own version aloud.</p></header><div class="interview-list"><details><summary>1. Why is String immutable?</summary><p>Immutability supports safe sharing, pooling, cached hashes, security and straightforward thread use.</p></details><details><summary>2. equals versus ==?</summary><p>equals tests String content; == asks whether two references identify the same object.</p></details><details><summary>3. When use StringBuilder?</summary><p>When text changes repeatedly, especially inside loops. Plain + is fine for a small fixed expression.</p></details><details><summary>4. What is the String pool?</summary><p>A JVM-managed table that allows equal interned strings, especially literals, to share one object.</p></details><details><summary>5. Can one char hold every character?</summary><p>No. char is one UTF-16 code unit; supplementary code points require a surrogate pair.</p></details></div></section><section class="lesson-section" id="practice"><header class="section-heading"><span>PROGRAMMING PROBLEMS</span><h2>Apply the Concept Independently</h2><p>Use the CodeBhavya online compiler.
